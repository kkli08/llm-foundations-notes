# 每日收集箱

`inbox` 用于保存当天尚未整理的原始材料。

## 文件命名

每天使用一个文件：

```text
inbox/YYYY-MM-DD.md
```

例如：

```text
inbox/2026-07-24.md
```

## 推荐格式

```markdown
# 2026-07-24 原始学习记录

## 今天的问题

- Batch 和并发到底有什么区别？
- Continuous Batching 为什么能提高吞吐？

## 对话或资料摘录

- …

## 我的当前理解

- …

## 实验与日志

- 配置：
- 现象：
- 预期：
- 未解释的问题：

## 下班前希望整理

- …
```

## 记录原则

- 白天先追求“不要遗漏”，不要求语言完整；
- 保留自己的问题和错误理解，它们很适合做复习题；
- 命令、配置、指标要尽量原样记录；
- 不要在 Inbox 中保存密码、Token、Cookie、私钥或公司敏感数据；
- 自动任务完成整理后，可以保留原始文件作为来源，也可以在文件顶部标记“已整理”；
- 没有实质内容时不要创建空 Inbox。
