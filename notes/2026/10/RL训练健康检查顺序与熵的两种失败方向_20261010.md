## 0. 今天最终要解决的问题

按提问顺序：

1. 两组归因实验现在哪个更正常？
2. 判断一个 RL 实验健不健康，第一反应应该按什么顺序看、看哪些指标？
3. 这么看两组的主要区别就是 KL 系数？

背景见 [多轮 Agent RL 的 Reward 崩溃](AgentRL的Reward崩溃与归因实验_20261009.md)：原配置在四五十步后输出塌缩、Reward 归零；A1 只把 KL 系数改为 0，A2 整套移植另一份稳定配方（其中也包含 KL 系数为 0、更低的采样温度等）。

## 1. 先给结论

- **Reward 是滞后指标**：等它掉了通常已经来不及。先看领先指标——熵和梯度范数，再看每轮输出长度和组级学习信号，最后用 Reward 确认。
- **熵有两个失败方向**：往上冲是不稳定（随后输出塌缩）；持续往下掉到接近 0 是多样性丧失（组内同分越来越多，学习信号变弱）。两种都要报警。
- **看趋势，不看绝对值**：降低采样温度本身就会让熵的绝对值偏低；判断标准是“相对自身早期水平”的变化。
- **“两组都改了 KL” ≠ “KL 就是原因”**：没跑过对照的崩溃区间、每组只跑一次时，任何一组暂时健康都可能是随机性。

## 2. 前置概念

### 2.1 领先指标与滞后指标

| 类别 | 例子 | 何时变化 |
|---|---|---|
| 领先 | 熵、梯度范数、每 Token KL 惩罚 | 策略分布开始变形时就变 |
| 中间 | 每轮输出长度、会话轮数、全零组占比 | 行为已经改变 |
| 滞后 | 任务 Reward | 行为改变已经影响到结果 |

在一次崩溃里，熵和梯度范数比 Reward 明显下跌早了约 10 步。

### 2.2 两种“组内没有差异”

GRPO 类方法靠组内差异产生 Advantage（[组内相对 Advantage 需要有差异的回答](../07/训练与RL后训练基础_20260724.md#514-组内相对-advantage-为什么需要有差异的回答)）。组内没有差异分两种：

| 指标 | 含义 | 典型原因 |
|---|---|---|
| 全零组占比 | 组内 G 条全部 Reward = 0 | 任务太难，或模型已崩 |
| 组内同分非零占比 | 组内 G 条 Reward 相同且非 0 | 任务对当前模型太容易，或采样多样性下降 |

两者都让这一组的任务 Advantage 为 0。前者上升指向“崩”，后者上升指向“学不动”。

## 3. 完整原理

### 3.1 健康检查的六步顺序

| 顺序 | 看什么 | 健康时 | 预警 / 已崩 |
|---|---|---|---|
| 1 | 是否还在正常训练：步时、每步更新是否成功 | 步时稳定，每步都成功更新 | 步时突然暴涨（凑不够有效样本）或突然减半（模型不再输出） |
| 2 | **熵** | 在自身早期水平附近波动 | 比早期高出约 30% 以上要警惕，冲到很高基本已崩；持续降到接近 0 是另一种风险 |
| 3 | **梯度范数** | 稳定在某个量级 | 持续明显高于平时要警惕；出现几十到几百倍的尖峰说明已崩 |
| 4 | 生成行为：每轮输出长度、每会话轮数 | 稳定 | 每轮输出明显变短，或轮数逼近上限（会话在空转） |
| 5 | 学习信号：全零组占比、组内同分非零占比、整组接收率 | 全零组占比低，接收率高 | 全零组占比升高；接收率骤降（大量整组被丢） |
| 6 | 结果：任务 Reward | 有波动但不持续下降 | 连续多步下降——此时通常已经晚了 |

第 1 步放最前，是因为后面所有读数都建立在“这一步确实完成了一次正常更新”上；步时减半在崩溃后常被误读成“加速”（见 [崩溃之后的数据怎么处理](AgentRL的Reward崩溃与归因实验_20261009.md#37-崩溃之后的数据怎么处理)）。

一句话：**第一眼看熵和梯度范数的趋势，第二眼看每轮输出长度和全零组占比，最后再用 Reward 确认。**

### 3.2 熵往上冲：不稳定的前兆

熵上升表示策略在每个位置上变得更“犹豫”，分布被拉平。在那次崩溃里，熵和梯度范数在预警区间一起抬头，随后每轮输出变短、全零组占比上升，Reward 最后才掉。机制与后续放大见 [10 月 9 日笔记 §3.1～3.2](AgentRL的Reward崩溃与归因实验_20261009.md#31-崩溃的时间顺序)。

### 3.3 熵持续往下掉：多样性丧失

另一组的走势正好相反：熵从早期水平一路降到接近 0，同时组内同分非零的组越来越多，Reward 暂时没受影响。

```text
熵持续下降
→ 同一 Prompt 的 G 条回答越来越像
→ 组内 Reward 完全相同的组变多
→ 这些组的 Advantage 为 0
→ 有效学习信号变少，探索变弱
```

这不是“熵爆、输出塌缩”那种崩法，但长期看同样危险：模型可能停在当前水平学不动。

**温度的影响**：采样温度从 1.0 降到 0.8，熵的绝对值本来就会偏低。所以“熵低”本身不说明问题，值得警惕的是它**一直在降**。不同温度的运行之间，不能直接比熵的绝对值。

### 3.4 “两组都把 KL 设成 0”能推出什么

用户的追问：这么看主要就是 KL 系数的区别？

能推出的：KL 系数为 0 是两组的**共同改动**。如果两组都没崩，它是最可疑的单项。

还不能推出的：

- **没过危险区间**：之前几组的崩溃起点分布在十几步的范围内；归因臂只跑过了对照的预警区间，至少要稳定越过所有对照中最晚的崩溃步才算数（[崩溃起点有运行间方差](AgentRL的Reward崩溃与归因实验_20261009.md#38-同期对照的逐步观察)）；
- **每组只跑一次**：一组暂时没崩，也可能只是这一次的随机性。

一个待验证的补充猜想（未核实）：KL 按 Token 计入 Reward，输出越短累计惩罚越少。当组内任务 Reward 完全相同时，组内样本之间**唯一的差别可能就只剩 KL 惩罚**，于是这部分组的更新方向几乎全由“少说话”决定，与“一开口就停”的症状方向一致。组内同分的组在训练中占比不小时，这股推力就不可忽略。这是 [10 月 9 日 §3.3 隐式长度惩罚](AgentRL的Reward崩溃与归因实验_20261009.md#33-可疑诱因kl-进-reward--γλ1-的隐式长度惩罚假设)的一个具体放大途径；此前检查 Reward 与 Advantage 时并没有发现短回答被奖励的直接证据，所以仍只是方向。对比时可以顺带看每步 KL 奖励项在崩溃前有没有异常变化。

## 5. 工程中的具体表现

| 现象 | 原因 | 如何验证 |
|---|---|---|
| Reward 还正常，熵和梯度范数已一起抬头 | 策略分布开始变形，Reward 滞后 | 与对照组同步数比熵、梯度范数曲线 |
| 熵一路降到接近 0，Reward 暂时不变 | 采样多样性下降 | 组内同分非零占比是否同步上升 |
| 两组熵的绝对值差很多 | 采样温度不同 | 只比各自相对早期水平的变化 |
| 步时突然减半 | 模型不再输出，不是系统变快 | 每轮输出长度、会话轮数 |
| 整组接收率骤降 | 大量整组被拒收 | 首发错误类型与整组拒收计数 |

## 6. 常见误解

| 容易误解为 | 更准确的理解 |
|---|---|
| 先看 Reward 判断实验是否健康 | Reward 最后才掉；先看熵和梯度范数 |
| 熵越低说明模型越确定、越好 | 持续下降到接近 0 是多样性丧失，组内差异消失，学习信号变弱 |
| 熵的绝对值可以跨运行比较 | 温度等采样参数会改变熵的量级，要看相对自身早期的趋势 |
| 组内同分只发生在全零组 | 同分非零（全对）的组同样没有任务 Advantage |
| 两组都改了某项、两组都没崩，就证明是它 | 还要越过最晚崩溃步，并考虑单次运行的随机性 |

## 7. 一分钟复习

1. 顺序：正常训练？→ 熵 → 梯度范数 → 每轮输出长度 → 全零/同分组占比、接收率 → Reward。
2. Reward 是滞后指标；熵和梯度范数可早约 10 步给出信号。
3. 熵往上冲 = 不稳定；熵往下掉到 0 = 多样性丧失；都要报警。
4. 温度改变熵的量级，只看趋势。
5. 共同改动最可疑，但要跑过最晚崩溃步、考虑单次随机性。

## 8. 自测问题

### 问题 1

为什么判断 RL 实验健康时，不应该第一眼看 Reward？

期望回答：Reward 是滞后指标，策略分布先变形（熵、梯度范数），然后行为改变（每轮输出长度、全零组），最后才影响结果；等 Reward 连续下降时通常已经晚了。

### 问题 2

一组实验的熵一路降到接近 0，Reward 还正常，需要担心吗？

期望回答：需要留意。熵持续下降意味着同一 Prompt 的回答越来越像，组内同分的组变多，这些组 Advantage 为 0，学习信号和探索都在变弱。但若采样温度较低，熵的绝对值本来偏低，判断依据是持续下降的趋势和组内同分占比的上升。

### 问题 3

A1、A2 都把 KL 系数设为 0，目前都健康，能下结论说 KL 是崩溃原因吗？

期望回答：还不能。它们还没越过对照组最晚的崩溃步；每组只跑一次，可能是随机性。若都稳定跑过危险区间，KL 是最可疑的共同改动，再用二分或重复实验确认。

## 9. 尚未解决与后续路线

- 两组归因臂越过危险区间后，按熵、梯度范数、每轮输出长度、Reward 做三组对比；
- “组内同分时 KL 成为唯一差异”的猜想需要用每步 KL 奖励项与同分组占比的时间关系验证；
- 熵持续下降是否会在更长训练中拖慢 Reward 提升，需要更长的观察窗口；
- 熵正则（Entropy Bonus）与温度、Clip 上界对熵走势的影响仍待系统学习。
