## 0. 今天最终要解决的问题

按提问顺序：

1. GRPO/GSPO 关掉批级 advantage 归一化的原理是什么来着？（第四次回到这个问题）
2. 例子表格里“组 B 第一个是 −1、其他是 0”是为什么？
3. 训练 reward 没有稳定上升，是不是就代表没学到东西？

## 1. 先给结论

- **批级归一化在 GRPO/GSPO 里是多余的一次**：组内归一化已经定好了零点和尺度；再按 token 加权做一次，会把零方差组平移成非 0，并让步长随“有信号组占比”变化。PPO 的 GAE 优势没有预先归一化，所以 PPO 要保留。
- **不升 ≠ 没学**：batch 均值主要随这批题的难度波动；信号只来自中间难度的题，被稀释；模型可能在学二值 reward 看不到的东西；T = 1 采样的 reward 滞后于贪心评测；按难度供题时 reward 本来就该持平。
- **升 ≠ 学对**：reward hacking、训练集过拟合、判分本身在变（判分失败被记 0 的比例在变）。
- **判断有没有在学，按三问组合**：策略在不在动（近似 KL、熵、clip 比例、梯度范数）？学习信号够不够（零方差组比例）？固定 held-out 评测有没有升？最终标准是 held-out。

## 2. 前置概念

### 2.1 两层归一化（复习）

| 层 | 统计范围 | 作用 | GRPO/GSPO | PPO |
|---|---|---|---|---|
| 组内 reward 归一化 | 同一题的 G 条回答 | 组均值当 baseline，组标准差定尺度 | 核心，保留 | 通常不做 |
| 批级 advantage 归一化 | 整批所有 token | 定零点与尺度 | 关掉 | 保留，稳定步长 |

详见 [两层归一化的拆解](GRPO变体与两层归一化的拆解_20261013.md)。

### 2.2 训练 reward 的统计性质

训练 reward 是“本步采样回答的平均得分”：每步换一批题、T = 1 采样、二值判分。题目只出现一次时，它近似同分布新题上的准确率（[训练判对率的含义](GSPO长跑对照的同步数读法与系统对比设计_20261021.md#32-训练判对率是什么指标问题-3)），但噪声来自三处：题目难度、采样随机性、判分本身。

## 3. 完整原理

### 3.1 复习：GRPO/GSPO 为什么关掉批级优势归一化

两组、各 2 条回答（无 critic、γ = λ = 1，每个 token 的优势 = 所在回答的组内优势）：

| 组 | 回答 | reward | token 数 | 组内归一化后 | 再做批级归一化后 |
|---|---|---|---|---|---|
| 组 A | 答对 | 1 | 100 | +1 | +1.89 |
| 组 A | 答错 | 0 | 300 | −1 | −1.13 |
| 组 B | 答错 | 0 | 200 | 0 | +0.38 |
| 组 B | 答错 | 0 | 200 | 0 | +0.38 |

- **当天的困惑**：表里那个 −1 属于**组 A 的答错回答**，原表同组第二行没写组名，看起来像归到了组 B。组 A 的 reward 是 [1, 0]，均值 0.5、标准差 0.5 → +1 / −1；组 B 全错，分子 0 − 0 = 0，分母 0 + eps → 两条都是 0。教训：每行都写组名。
- **副作用 1：零点被挪**。组内归一化保证“按回答数平均为 0”，不保证“按 token 数平均为 0”。token 加权 μ = (100 × 1 − 300 × 1) / 800 = −0.25，σ = √(0.5 − 0.0625) ≈ 0.66 → 全错的组 B 被推成 +0.38，模型被鼓励复现错误答案。错的回答往往更长 → μ 通常偏负 → 每一步所有零方差组都被同一个常数往正方向推。
- **副作用 2：步长随数据组成变**。零方差组贡献一大片 0、把 σ 压小。回答等长时：32 组里 1 组有信号 → σ ≈ √(1/32) ≈ 0.18，放大约 5.7 倍；16 组有信号 → σ ≈ 0.71，放大约 1.4 倍。等于一个随“太难或太简单的题占比”变化的隐式学习率，训练后期题目大多全对时放得最大（[除以 σ 拆掉刹车](截断采样与批级归一化的双条件崩溃机制_20261016.md#310-修订主因是除以-σ-拆掉了刹车)）。
- **为什么 PPO 保留**：GAE 优势是 `r − V` 的累积，没有预先中心化，尺度随 reward 量级与 value 误差变化，批级归一化在稳定步长。所以这是配方问题：GRPO/GSPO 的配方里显式关掉，而不是删掉这个组件；支持 PPO 时它按什么加权反而很重要。

### 3.2 为什么 reward 不升，不代表没在学

| 原因 | 机制 | 更敏感的读数 |
|---|---|---|
| 每步噪声大 | 每步换一批题，均值主要随难度波动。粗估：每步 128 题、题间解出率标准差约 0.3 → 标准误 ≈ 0.3/√128 ≈ 0.03；相邻几步在 ±0.03 内跳就是噪声 | 几十步滑动平均；按难度分桶 |
| 信号被稀释 | 全对、全错组优势为 0、不贡献梯度；模型可能正把“偶尔做对”的题练成“稳定做对”，但这批题占比小 | 全对组比例升、全错组比例降 |
| 学的是 reward 看不见的东西 | 回答变短、轮数变少、截断与超时变少、格式错误变少；同样解出一道题、用的步数少了，二值 reward 看不出 | 长度、轮数、截断率、超时率、格式错误率 |
| 采样温度 | 训练 reward 在 T = 1 下采样；策略变尖（熵下降）后贪心或低温评测可能已明显变好 | 低温 / 贪心的 held-out 评测 |
| 供题方式 | 按难度筛题、动态采样、在线平台持续下发更难的任务 → reward 被刻意维持在中间水平 | 看数据管线是否自适应难度 |

### 3.3 为什么 reward 上升，也不一定学对了

- **reward hacking**：钻判分规则或 judge 的空子（格式、长度、固定套路）；
- **训练集过拟合**：训练 reward 升，held-out 不涨（每题只出现一次时这条较弱）；
- **判分本身在变**：判分超时被记 0 的比例下降，reward 曲线就会上升，和模型能力无关（[共享 judge 的“超时记 0”](附加模型的显存编排与判分服务设计_20261026.md#37-共享-judge竞争不大耦合才是风险)）；截断率下降同理（[截断伪造的 Reward 涨幅](Benchmark对照的负载等价与读数混杂_20261009.md#32-截断伪造的-reward-涨幅)）；actor 冻结时 reward 也会随批次难度涨（[10 月 23 日 §3.7](生成长度上限的意义与长跑对照的读数口径_20261023.md#37-actor-冻结reward-也会涨)）。

### 3.4 判断有没有在学：看什么

| 想回答的问题 | 看什么 |
|---|---|
| 真实能力有没有提升 | 固定 held-out 评测：同分布、固定题目、固定采样方式，定期评。这是最终标准 |
| 策略有没有在动 | 行为侧近似 KL / 与 ref 的 KL、熵、clip 比例、梯度范数；KL 与 clip 比例都接近 0 → 策略几乎没变，确实没在学 |
| 学习信号够不够 | 零方差组比例，全对、全错分开看 |
| 是不是在学 reward 之外的东西 | 长度、轮数、截断率、超时率、格式错误率 |
| reward 本身可不可信 | 判分失败与超时比例、整组被丢弃的比例（陈旧度、中止） |
| 平滑趋势 | 滑动平均，最好按难度分桶 |
| PPO 的 critic 有没有在学 | explained variance（[EV 上限](PPO_Critic的价值头初始化两种预热与EV上限_20261021.md)） |

### 3.5 组合起来下结论

| 策略在动？ | held-out 升？ | 结论 | 下一步 |
|---|---|---|---|
| 是 | 是 | 在学；训练 reward 平只是噪声或被稀释 | 继续 |
| 是 | 否 | 在学 reward 之外的东西，或 hacking / 过拟合 | 看长度、格式和具体样本 |
| 否 | — | 没在学 | 先查学习信号：零方差组是否占绝大多数、学习率是否太小、样本是否大量因陈旧度或中止被丢、优势是否被异常缩放（如 §3.1）、判分是否大面积失败 |

一条训练 reward 曲线最多说明“模型在这批题上的平均表现”，单独回答不了“学没学到东西”。它是滞后指标（[健康检查六步顺序](RL训练健康检查顺序与熵的两种失败方向_20261010.md#31-健康检查的六步顺序)），放在检查顺序的最后。

## 5. 工程中的具体表现

| 现象 | 原因 | 如何验证 |
|---|---|---|
| 相邻几步 reward 在 ±0.03 内跳 | 每步换题的难度噪声 | 算标准误；看滑动平均 |
| reward 持平但全对组比例在升 | 中间难度的题在被练熟，被大量无信号组稀释 | 分开统计全对 / 全错组比例 |
| reward 持平但长度、截断率在降 | 学的是 reward 之外的效率 | 看长度与截断率曲线 |
| reward 在升，held-out 不升 | hacking、过拟合或判分失败比例在变 | 抽样看高分回答；看判分失败比例 |
| reward 不动，KL 与 clip 比例接近 0 | 策略没在动 | 查零方差组占比、学习率、丢样本、优势缩放 |
| GRPO 后期全对组变多后梯度范数变大 | 批级归一化的 σ 被压小、放大倍数上升 | 关掉批级归一化对照 |

## 6. 常见误解

| 容易误解为 | 更准确的理解 |
|---|---|
| reward 不稳定上升 = 没学到东西 | 主要随批次难度波动、被无信号组稀释，且看不到 reward 之外的进步 |
| reward 在升 = 学对了 | 可能是 hacking、过拟合或判分失败比例在变 |
| 组内归一化后再批级归一化更稳 | GRPO/GSPO 里没有新信息，只带来平移与随组成变化的放大 |
| 批级归一化是 bug，应该删掉 | 是配方问题：PPO 需要它，GRPO/GSPO 在配置里关掉 |
| 表里的 −1 属于全错组 | 属于有信号组 A 的答错回答；全错组组内归一化后都是 0 |

## 7. 一分钟复习

1. 组内归一化定零点和尺度；批级归一化按 token 加权 → 零方差组被平移（μ 通常偏负 → 全错组变正）+ 除以 σ 的放大随有信号组占比变（1/32 → 5.7 倍，16/32 → 1.4 倍）。
2. PPO 的 GAE 优势没预先归一化 → 保留；GRPO/GSPO 在配置里关掉。
3. 不升 ≠ 没学：难度噪声（标准误约 0.03）、信号被稀释、学 reward 外的东西、T = 1 滞后、自适应供题。
4. 升 ≠ 学对：hacking、过拟合、判分失败比例在变。
5. 判读：策略在动？× held-out 升？；策略不动先查学习信号。

## 8. 自测问题

### 问题 1

两组各 2 条回答，token 数 100/300/200/200，组内归一化后为 +1/−1/0/0。手算 token 加权的批级归一化结果，并说明对 GRPO 的两个副作用。

期望回答：μ = (100 − 300)/800 = −0.25，E[A²] = 400/800 = 0.5，σ = √(0.5 − 0.0625) ≈ 0.66；结果 +1.89 / −1.13 / +0.38 / +0.38。副作用一：全错组被推成正优势，模型被鼓励复现错误答案，且错的回答更长使 μ 通常偏负；副作用二：σ 被零方差组压小，放大倍数随有信号组占比变化，相当于随数据组成变化的隐式学习率。

### 问题 2

为什么 PPO 要保留批级优势归一化，GRPO/GSPO 却要关掉？

期望回答：PPO 的 GAE 优势是 r − V 的累积，没有预先中心化，尺度随 reward 量级与 value 误差变化，批级归一化在稳定步长；GRPO/GSPO 的优势已经组内中心化、标准化，再做一次没有新信息，只带来平移和放大两个副作用。

### 问题 3

训练 reward 二十步内基本持平，能不能下结论“没在学”？要补看哪些读数？

期望回答：不能。先算噪声量级（标准误约 0.03 量级），看几十步平滑与按难度分桶；看全对 / 全错组比例的变化；看长度、截断率、格式错误等 reward 之外的指标；看策略是否在动（近似 KL、熵、clip 比例、梯度范数）；最终看固定 held-out 评测。若策略几乎不动，再查零方差组占比、学习率、丢样本、优势缩放和判分失败。

### 问题 4

训练 reward 稳定上升，有哪些情况不代表学对了？

期望回答：reward hacking（钻格式、长度或 judge 的空子）；训练集过拟合（held-out 不涨）；判分本身在变，例如判分超时被记 0 的比例下降、截断率下降，都会让 reward 上升而与能力无关。

## 9. 尚未解决与后续路线

- 训练 reward 标准误的更精确估计：把题间方差与题内采样方差分开；
- 按难度分桶的 reward 曲线怎么设计桶（用基座模型的解出率还是训练中动态估计）；
- “策略在动”的阈值：近似 KL、clip 比例多小算“几乎不动”；
- 只减均值 / 只除标准差的拆开验证仍待做（见 [10 月 16 日 §3.10](截断采样与批级归一化的双条件崩溃机制_20261016.md#310-修订主因是除以-σ-拆掉了刹车)）。
