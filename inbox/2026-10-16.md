>
> 来源：Claude Code 会话 `60e4e2ab`

### 今天的问题

- 是不是因为 GRPO 是在 PPO trainer 上改出来的？PPO 需要它是因为要让长短不一的轨迹里每个 token 影响一致？PPO 的归一化是 token 级？
- 所以 PPO 做它是为了让每个 token 更新幅度一致吗？不做会怎样？组内 z-score 具体怎么算？

### 我的当前理解（含被纠正的部分）

- 对的部分：配置确实沿用自 PPO；GRPO 只是同一个 Actor 的一组配置；PPO 的批级归一化是 token 级的，因为 PPO 的 Advantage 本来逐 token 不同；
- 被纠正：批级归一化不是让每个 token 更新幅度一致，而是固定整体尺度、把均值拉回 0；长短轨迹的权重归 loss 聚合方式管；
- 整理时补充的修正：归一化是仿射变换，保留顺序和差值的相对大小，不保留比值（对话里“比例关系不变”的说法不准确）；
- 对照开源 veRL：GRPO 只做组内 z-score，批级白化只在 GAE（PPO）路径里。

>
> 来源：Claude Code 会话 `60e4e2ab`

### 今天的问题

- 零方差组明显拿到了错误信号，为什么 top_p = 1 那组也没崩？（第一遍公式太多没看懂，换例子重讲）
- 只是一个位置的词表概率，给它加 Advantage 会影响其他轨迹、其他 token 吗？Advantage 最后怎么进 loss？
- 截断是不是体现在 ratio 上：分子是截断后的新分布，分母是采样时的分布？

### 对话或资料摘录

- 常数 Advantage：从 π 采样时期望梯度为 0（Baseline）；截断后期望是 ∇log Z，有了固定方向；
- “抵消”不是发生在一个 token 内部，而是整批几十万个期望为 0 的推力加总时；每个位置只采一次（最初“同一位置采 100 次”的讲法有误导）；
- Advantage 经 softmax 影响同一位置整个词表，经共享参数影响所有上下文；
- 被纠正：ratio 的分子分母都是完整分布，截断改变的是样本；正确分母应是 q = π/Z；
- 一次小波动后，只有“截断 + 批级归一化”那组循环增益 > 1；
- 未解决：c > 0 时直觉上应让分布更尖，实际却是熵上升、开头即 EOS。

>
> 来源：Claude Code 会话 `e5a8f9d2`

### 今天的问题

- 这个比值具体有啥用？实验里用到了吗？都开了重算还有意义吗？
- 算 KL 是用这个算的吗？那还要 Ref 模型做什么？

### 对话或资料摘录

- 被纠正：把“行为侧近似 KL”（诊断量）和 KL 正则混成了一件事；名字带 KL 的指标至少四个，只有 KL 奖励/KL loss 是正则、需要 Ref；
- KL 系数为 0 且不开 KL loss 时，框架可能根本不创建 Ref；
- 行为侧权重是唯一还在起作用的 off-policy 修正；健康期均值≈1、拒绝采样几乎不触发；崩溃期大量过滤，起安全阀作用；
- 漏洞：分母是 raw logprob，温度偏差被当成陈旧度加权，截断的 1/Z 看不见；
- 实现细节：有的实现只在配置拒绝采样时才把行为侧权重乘进 loss。
