# PPO / GRPO / GSPO 复习路线

> 覆盖知识发生区间：2026-07-24～10-16，以 10 月 9～16 日为主；整理：2026-10-16。本页只做串联、统一符号与纠错汇总，细节都在各篇正式笔记里；标“假说”的内容尚未被数据验证。

## 先用一分钟补齐主线

RL 后训练对模型只用两个接口：**采样**，以及**对已有文本算逐 token logprob**。所有策略梯度算法共用一个骨架：

```text
loss = −A × (π_θ / π_old)，再用 clip 给“同一批数据多次更新”限速
```

PPO、GRPO、GSPO 只在三个位置不同：**Advantage 从哪来**（Critic + GAE，还是同题多次采样的组内比较）、**ratio 按什么单位算**（每个 token 还是整条序列）、**归一化与聚合怎么做**。

工程上又多了两层：异步训推把 π_old 拆成 π_behave（推理引擎采样时记的）和 π_prox（训练引擎重算的）；温度与 top-p/top-k 截断让真正采样用的 q 与这两者都不一样。训推偏差大多出在这些分布的**口径**上。

最后，部件单独看都合理，组合起来才出问题：GRPO 沿用 PPO 的批级 Advantage 归一化，再碰上截断采样，就是 10 月这次 Reward 崩溃的因果链（见下方案例）。

## 统一符号

| 符号 | 含义 | 首次详解 |
|---|---|---|
| π_behave | 推理引擎采样时返回的 logprob（raw：截断前、通常温度前） | [10 月 14 日](../notes/2026/10/采样截断与Logprob口径的训推偏差_20261014.md) |
| q | 真正采样用的分布：温度后截断、核内重新归一化，**没人记录** | [10 月 16 日](../notes/2026/10/GRPO训练步的参数时序与四个KL指标_20261016.md) |
| π_prox | 训练引擎用当前权重、不求梯度重算的 logprob | [10 月 13 日 §3.4](../notes/2026/10/PPO的Critic与Clip在单次更新下的退化_20261013.md) |
| π_θ | 训练时带梯度的前向，梯度从这里走 | 同上 |
| π_ref | 冻结的起跑 Checkpoint，只为 KL 正则存在 | [10 月 13 日 §3.1](../notes/2026/10/PPO的Critic与Clip在单次更新下的退化_20261013.md) |

| w = π_prox/π_behave | 行为侧重要性权重，过大时被拒绝采样 mask | 同上 |
| r̂ = (r − m)/(s + ε) | 组内 z-score，每条轨迹一个数 | [10 月 16 日 §2.1](../notes/2026/10/截断采样与批级归一化的双条件崩溃机制_20261016.md) |
| A_t | 每个 token 的 Advantage；GRPO 下 ≈ r̂ 广播 | [10 月 12 日 §2.2](../notes/2026/10/GRPO流程与批级Advantage归一化的偏移机制_20261012.md) |
| μ、σ | 批级归一化按 token 统计的均值与标准差 | [10 月 13 日](../notes/2026/10/GRPO变体与两层归一化的拆解_20261013.md) |
| β | KL 系数 | [10 月 15 日](../notes/2026/10/KL估计器与放置位置的设计动机_20261015.md) |
| Z | 截断后核内的总概率，q = π/Z | [10 月 14 日](../notes/2026/10/采样截断与Logprob口径的训推偏差_20261014.md) |

## 三个算法差在哪

| | PPO | GRPO | GSPO |
|---|---|---|---|
| Advantage 来源 | Critic 估 V，GAE 逐 token 算 | 同题 G 次采样做组内 z-score，每条轨迹一个数 | 同 GRPO |
| 需要的模型 | Actor、Critic、（Ref）、Reward | Actor、（Ref）、Reward | 同 GRPO |
| ratio 单位 | token | token | 整条序列（log ratio 平均后取 exp） |
| clip ε 量级 | ≈ 0.2 | ≈ 0.2 | ≈ 1e-4 |
| 批级 Advantage 归一化 | 常用稳定技巧 | 原版没有；有些框架默认带着，成了重复的第二次归一化 | 同 GRPO |
| 用什么换什么 | 多一个同尺寸模型，换轨迹内功劳分配 | G 倍采样 + 组内等待，换掉 Critic | 序列级 ratio，换对单 token 抖动不敏感 |

GRPO 的变体（Dr.GRPO、DAPO、RLOO、LitePPO……）大多只差在三处：**Advantage 怎么归一化、Loss 怎么聚合、Clip 怎么设**（[10 月 13 日 §3.1、§3.8](../notes/2026/10/GRPO变体与两层归一化的拆解_20261013.md#31-原版-grpo-的已知问题与对应变体)）。

## 一个训练步的统一时间线

```text
① 采样    logits ÷T → softmax = π → top-k → top-p → 核内重新归一化 = q → 采样；记 log π_behave（raw）
② 打分    一条轨迹一个 Reward
③ 重算    log π_prox = log_softmax(logits/T)（完整词表）；开 KL 时算 log π_ref
④ 优势    组内 z-score → （KL 奖励）→ GAE 广播（V≡0, γ=λ=1）→ （批级归一化，整批一次）
⑤ 损失    max(−A·r, −A·clip(r)) × w；w 过大则 mask；token 等权或轨迹等权聚合
⑥ 同步    新权重推给推理引擎
```

每个旋钮生效在哪一段，见 [10 月 16 日 §3.2](../notes/2026/10/GRPO训练步的参数时序与四个KL指标_20261016.md#32-每个旋钮在哪一段生效)。要记住的三件事：top-k/p 只在 ①；T 在 ① 和 ③；**整批只更新一次时 r ≡ 1、clip 不触发，起作用的只剩 A 与 w**。

## 必须记住的纠错

**流程与算法**

- GRPO 和 PPO 不是两套 loss：共用 clip surrogate，只差 Advantage 来源（[10/12](../notes/2026/10/GRPO流程与批级Advantage归一化的偏移机制_20261012.md)）。
- 配置里写了 GAE 不等于在跑 PPO：V ≡ 0、γ = λ = 1 时 GAE 只是广播，唯一多做的是累加 KL 奖励（[10/15](../notes/2026/10/温度偏差实测与KL放置位置_20261015.md)）。
- PPO/GRPO 是训练循环，不是模型结构；只有 Critic 换了输出头（[10/13](../notes/2026/10/PPO的Critic与Clip在单次更新下的退化_20261013.md)）。
- PPO + GAE 不一定比 GRPO 分配功劳更准：长程稀疏 Reward 下 Critic 难训，λ 只能接近 1（[10/13](../notes/2026/10/PPO的Critic与Clip在单次更新下的退化_20261013.md)）。
- GSPO 不是新的 Advantage 算法：只改 ratio/clip 的单位，ε 要小几个数量级（[10/14](../notes/2026/10/GSPO序列级比率与PPO论文精读_20261014.md)）。

**归一化**

- 组内比较在 Reward 归一化（按条数）；Advantage 归一化是 PPO 的通用后处理（按 token）（[10/13](../notes/2026/10/GRPO变体与两层归一化的拆解_20261013.md)）。
- “按 token”是统计口径，不是单独一步；它和 loss 的 token 等权是两件事（[10/13](../notes/2026/10/GRPO变体与两层归一化的拆解_20261013.md)）。
- 批级归一化影响每个 token，不只零方差组；整批只算一次，再切 minibatch（[10/15](../notes/2026/10/温度偏差实测与KL放置位置_20261015.md)）。
- PPO 做批级归一化是为了固定尺度、均值归 0，不是让每个 token 更新幅度一致；它保留顺序和差值的相对大小，不保留比值（[10/16](../notes/2026/10/截断采样与批级归一化的双条件崩溃机制_20261016.md)）。
- 给所有 token 加常数不一定有害：从 π 采样时是 Baseline；截断后才有方向（[10/12](../notes/2026/10/GRPO流程与批级Advantage归一化的偏移机制_20261012.md)、[10/16](../notes/2026/10/截断采样与批级归一化的双条件崩溃机制_20261016.md)）。
- 截断采样单独不会崩，开批级归一化单独也不会崩（[10/16](../notes/2026/10/截断采样与批级归一化的双条件崩溃机制_20261016.md)）。

**比值与 Clip**

- 单次更新时只有 `π_θ/π_prox` 恒为 1；它仍是梯度来源；`π_prox/π_behave` 照常修正（[10/15](../notes/2026/10/单次更新下两个比值的分工与Clip的真实作用_20261015.md)）。
- Clip 从不限制单独一步，只限制同一批数据多次更新的累积偏移（[10/15](../notes/2026/10/单次更新下两个比值的分工与Clip的真实作用_20261015.md)）。
- 比值不加进 Advantage：Advantage 先算好、固定，比值在 loss 里与它相乘（[10/15](../notes/2026/10/单次更新下两个比值的分工与Clip的真实作用_20261015.md)）。
- 开了重算，推理端 logprob 仍是行为侧权重的分母；logprob 重算也不是激活重算（[10/15](../notes/2026/10/单次更新下两个比值的分工与Clip的真实作用_20261015.md)）。
- 截断不在比值的分子或分母里：两边都是完整分布，偏差在样本里（[10/16](../notes/2026/10/截断采样与批级归一化的双条件崩溃机制_20261016.md)）。

**KL**

- 名字带 KL 的指标多数是诊断量；只有 KL 奖励/KL loss 是正则，也只有它需要 Ref（[10/16](../notes/2026/10/GRPO训练步的参数时序与四个KL指标_20261016.md)）。
- k1、k3 都无偏，但 k1 进 loss 的期望梯度为 0；reward 用 k1、loss 用 k3（[10/15](../notes/2026/10/KL估计器与放置位置的设计动机_20261015.md)）。
- KL 进 reward 是 PPO-RLHF 的标准写法，不是为异步设计的（[10/15](../notes/2026/10/KL估计器与放置位置的设计动机_20261015.md)）。
- KL 和批级归一化是两个独立开关；同时开两种 KL 等于加两次（[10/15](../notes/2026/10/KL估计器与放置位置的设计动机_20261015.md)）。

**训推偏差与诊断**

- 推理端返回的 logprob 不是采样分布，是温度前、截断前的 raw 分布（[10/14](../notes/2026/10/采样截断与Logprob口径的训推偏差_20261014.md)）。
- 训推不一致飙升出现在熵上升之后，是崩溃的结果，不是诱因（[10/15](../notes/2026/10/温度偏差实测与KL放置位置_20261015.md)）。
- Reward 是滞后指标；先看熵、长度、零方差组构成这些领先指标（[10/10](../notes/2026/10/RL训练健康检查顺序与熵的两种失败方向_20261010.md)）。

## 跨笔记自测

1. 写出 GRPO 从 Reward 到 loss 的每一步，标出哪一步提取信号、哪些步只是管道。
   期望回答：组内 z-score 是唯一提取信号的一步；KL 奖励、GAE 广播、批级归一化、ratio/clip、w 都是管道，要么原样保留信号，要么扭曲它。
2. 为什么 PPO 的批级归一化在 PPO 里合理，到 GRPO 里有害？
   期望回答：PPO 的 Advantage 逐 token 连续、此前没归一化过；GRPO 已做组内 z-score，再按 token 统计就变成按长度加权的跨组归一化，把零方差组平移成非 0，零方差组越多放得越大。
3. 推导常数 Advantage 在 π 下和在截断 q 下的期望梯度。
   期望回答：$\mathbb{E}_\pi[\nabla\log\pi] = \nabla\sum\pi = 0$；$\mathbb{E}_q[\nabla\log\pi] = \nabla Z/Z = \nabla\log Z$。
4. 整批只更新一次时，clip-higher 和序列级 ratio 开关为什么基本不生效？什么还在生效？
   期望回答：r ≡ 1，clip 不触发，一串 1 的几何平均还是 1；还在生效的是 A 与行为侧权重 w（含拒绝采样）。
5. 一次训练步里有哪五个分布？哪一个没人记录？
   期望回答：π_behave、q、π_prox、π_θ、π_ref；q 没人记录。
6. KL 进 reward 和进 loss 分别约束什么？各用哪个估计器，为什么不能反过来？
   期望回答：进 reward 约束整条序列的 KL 总量，用 k1 走策略梯度；进 loss 只管当前 token，用 k3。k1 直接进 loss 求导的期望梯度为 0。
7. 行为侧近似 KL 不为 0，能说明模型离起跑权重远了吗？
   期望回答：不能。它比较 π_prox 与 π_behave，反映陈旧度与训推差；离起跑权重多远要看与 π_ref 的 KL。
8. GSPO 为什么把 clip 范围设到 1e-4 量级？
   期望回答：序列 ratio 是几何平均，单 token 噪声被摊薄，s_i 极接近 1；还用 0.2 等于没有 clip。
9. GRPO 用什么换掉了 Critic？代价在多轮 Agent 任务里为什么变大？
   期望回答：同题 G 倍采样与组内等待；时长差异大时一条卡住的会话拖住整组，等待中数据变旧，组超时还会整组作废。
10. 截断采样为什么让被截掉的词“永远不会被纠正”？
    期望回答：它们永远采不到，不进 batch，就拿不到负 Advantage；被压低的头部概率还会流向它们。
